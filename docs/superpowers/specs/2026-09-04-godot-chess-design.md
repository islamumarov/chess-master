# Chess Master — Godot 4 chess vs. minimax AI (design record)

Spec source: user prompt of 2026-09-04 (full feature list). This file records the
decisions made while building it, not the feature list itself.

## Layers

| Layer | Files | Notes |
|---|---|---|
| Engine (pure logic, thread-safe) | `scripts/chess/chess_position.gd`, `chess_move.gd`, `notation.gd` | No scene-tree access. Used by AI on a worker thread. |
| AI | `scripts/ai/chess_ai.gd` | Negamax + alpha-beta, iterative deepening, quiescence, killer moves, MVV-LVA ordering. |
| View | `scripts/ui/board_view.gd`, `piece_textures.gd`, `promotion_dialog.gd` | Board drawn in `_draw()`; pieces are TextureRect children (tweened). |
| Flow / UI | `scripts/ui/game_controller.gd` (Main), `side_panel.gd` | Controller owns the position, runs the AI thread, updates panel. |

## Key decisions

- **Board**: `PackedInt32Array(64)`, `piece = color * type` (white +, black −), a1 = 0.
- **Moves**: packed ints (from | to<<6 | promo<<12 | flag<<15). No per-move object
  allocation, so GDScript search stays fast. `ChessMove` static helpers decode.
- **Undo**: one `PackedInt64Array` record per ply (move, captured, castling, ep, halfmove)
  plus a Zobrist hash history. Powers both AI unmake and the UI Undo button.
- **Repetition**: Zobrist hashing (incremental). Threefold for the game, twofold = draw inside search.
- **Legality**: pseudo-legal generation + make/`in_check`/unmake filter. Attack detection
  scans outward from the target square (cheaper than generating enemy moves).
- **AI threading**: search runs on a `Thread` against a deep copy of the position; result
  returned via `call_deferred`. A search id discards stale results after Undo/New Game.
- **Time control**: depth is the user setting (1–6); a soft time cap stops iterative
  deepening so a high depth never freezes the game.
- **Pieces**: own flat SVG set generated by `tools/gen_assets.py` (no downloads). Swap any
  12 `assets/pieces/{w,b}{K,Q,R,B,N,P}.svg` files to change the set.
- **Sounds**: 4 tiny procedurally generated WAVs from the same script.
- **Test**: `tests/perft.gd` — perft node counts on standard positions (castling, en passant,
  promotion, checks), FEN round-trip, mate/stalemate detection, SAN, AI mate-in-1.
  Run: `godot --headless --path . --script tests/perft.gd`
